GUIA DE DESPLIEGUE GRATIS 24/7: RENDER + TIDB CLOUD + UPTIMEROBOT
Proyecto: UniSpacePro (Laravel 12 + MySQL)
========================================================================

PASO 1: SUBIR EL PROYECTO A GITHUB
1. Crea un repositorio en GitHub (puede ser publico o privado).
2. Sube todo el proyecto (incluyendo Dockerfile, .dockerignore y docker/start.sh).
   Nota: El archivo .env local NO se sube a GitHub por seguridad.

------------------------------------------------------------------------
PASO 2: CREAR LA BASE DE DATOS GRATIS EN TIDB CLOUD (COMPATIBLE CON MYSQL)
1. Entra a https://tidbcloud.com/ y crea una cuenta gratuita (no pide tarjeta).
2. Crea un cluster "Serverless" (Plan Starter / Free).
3. En el panel del cluster, haz clic en "Connect" -> "Standard connection" y anota:
   - Host (ej: gateway01.us-east-1.prod.aws.tidbcloud.com)
   - Port: 4000
   - User (ej: xxxxx.root)
   - Password (la que generes en el panel)
4. Crea la base de datos e importa los datos:
   - En el "SQL Editor" web de TiDB Cloud, crea la base de datos:
       CREATE DATABASE IF NOT EXISTS unispacepro;
       USE unispacepro;
   - O desde tu PC (con MySQL de XAMPP) puedes importar todo el archivo directamente:
       C:\xampp\mysql\bin\mysql.exe -h TU_HOST -P 4000 -u "TU_USUARIO" -p --ssl-mode=VERIFY_IDENTITY unispacepro < database\unispacepro_actualizado.sql

------------------------------------------------------------------------
PASO 3: DESPLEGAR LARAVEL EN RENDER (GRATIS)
1. Entra a https://render.com/ e inicia sesion con tu cuenta de GitHub.
2. Haz clic en "New +" -> "Web Service" y selecciona tu repositorio de GitHub.
3. En "Language / Runtime" elige: Docker.
4. En "Instance Type" elige: Free ($0/month).
5. En "Environment Variables" agrega exactamente estas variables:

   APP_NAME=UniSpacePro
   APP_ENV=production
   APP_KEY=base64:uQu+bTbctPPGA/NJvdk/6PUrOgcmjbPgshtiA5Q6qR8=
   APP_DEBUG=false
   APP_URL=https://TU-SERVICIO.onrender.com

   DB_CONNECTION=mysql
   DB_HOST=TU_HOST_DE_TIDB
   DB_PORT=4000
   DB_DATABASE=unispacepro
   DB_USERNAME=TU_USUARIO_DE_TIDB
   DB_PASSWORD=TU_PASSWORD_DE_TIDB
   MYSQL_ATTR_SSL_CA=/etc/ssl/certs/ca-certificates.crt

   SESSION_DRIVER=file
   CACHE_STORE=file
   QUEUE_CONNECTION=sync

   MAIL_MAILER=smtp
   MAIL_HOST=smtp.gmail.com
   MAIL_PORT=465
   MAIL_USERNAME=unispace41@gmail.com
   MAIL_PASSWORD=TU_APP_PASSWORD_DE_GMAIL
   MAIL_ENCRYPTION=ssl
   MAIL_FROM_ADDRESS=unispace41@gmail.com
   MAIL_FROM_NAME=UnispacePro

6. En "Health Check Path" coloca: /up
7. Pulsa "Deploy Web Service". Render construira el Dockerfile y te dara tu URL publica https://...onrender.com.

------------------------------------------------------------------------
PASO 4: MANTENERLO ACTIVO 24/7 GRATIS (EVITAR QUE RENDER SE DUERMA)
El plan gratuito de Render da 750 horas gratis al mes (suficiente para 1 servicio 24/7,
ya que un mes tiene ~720-744 horas), pero suspende el servicio tras 15 minutos sin visitas.

Para mantenerlo despierto las 24 horas gratis:
1. Entra a https://uptimerobot.com/ y crea una cuenta gratuita.
2. Haz clic en "Add New Monitor":
   - Monitor Type: HTTP(s)
   - Friendly Name: UniSpacePro
   - URL: https://TU-SERVICIO.onrender.com/up
   - Monitoring Interval: 5 minutes
3. Guarda el monitor. UptimeRobot consultara /up cada 5 minutos y tu pagina
   permanecera activa 24/7 sin dormirse.

NOTA IMPORTANTE SOBRE FOTOS NUEVAS EN RENDER FREE:
Las fotos que ya estan dentro del repositorio (public/images/...) se veran siempre.
Sin embargo, en el plan gratuito de Render el disco se reinicia cada vez que
redespliegas o se reinicia el contenedor, por lo que una foto nueva subida desde
la web no persistira tras un reinicio (a menos que se conecte un bucket S3/Cloudinary).
